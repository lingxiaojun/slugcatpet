# 能力与行为参数

> 本文件由 `python tools/params_doc.py` 从代码生成，请勿手改。
> 角色怎么写见 [CHARACTERS.md](CHARACTERS.md)，整体结构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

角色定义（`slugcatpet/resources/characters/<key>.json`）里这样覆盖参数：

```json
"abilities": {"tongue": {"ceiling_drop": false}, "ascension": {}},
"behaviors": {"cursor_lick": {"dwell_ticks": 120}, "dodge_kill": false}
```

- `abilities`：这只猫有哪些能力（键）以及参数覆盖（值，`{}` = 全用默认）。
- `behaviors`：行为按身体标签自动挂载，这里只写例外：`false` 关掉，对象 = 覆盖参数。
- 身体标签：默认的 `mouth`，加上各能力 key 和能力提供的标签，再去掉能力移除的标签。
- 带心情候选的行为，权重还会乘以性格权重（精力换算的好动度 × `toy_pref[心情名]`）。

## 性格

角色 JSON 的 `personality` 各轴作用如下，换算都在 `characters/personality.py` 的 `Traits` 里。

| 轴 | 作用 |
|---|---|
| `energy` | 心情候选权重、玩耍体力门、东张西望和踱步频率；懒的发呆更久、常趴着、更容易困 |
| `sympathy` | 发呆走位靠近或远离其他猫；好感涨跌快慢、舔光标前等多久；高的吃饱后不想打猎 |
| `vary` | 新猫的个体性格（energy、sympathy）在默认值附近随机的幅度 |
| `toy_pref` | 按心情名单独调权重 |
| `stamina` | 体力消耗 |
| `cold_gain_fac` | 暴风雪里变冷的速度 |
| `swim_zeal` | 漂游最大深度、潜泳冲刺距离 |
| `diet` | 哪些可食物会去吃、肉的优先度、吃一样得多少饱食（肉食者 1/4 格） |
| `meat` | 能不能啃尸体、每口得多少饱食 |
| `kin` | 和哪种猫一见面就关系好 |

## 能力

### 舌头 `tongue`

射舌粘住东西收绳。规划器多出舌够、舌爬墙、竖杆舌钩、舌吊驻留、吊顶落下几种够取，取果时可在空中抢射补救。

- 内置角色：`saint`
- 随之挂载的行为：`seek_hpole`、`wall_climb`、`cursor_lick`、`dodge_kill`、`zerog_lick`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `ceiling_drop` | true |  | 规划器可用爬上天花板、横移后松舌落下的够取，代价最高，作兜底 |

### 超度 `ascension`

业力满时可超度：悬浮升空 + 全屏幽灵触手特效（何时触发见行为 ascend）。

- 内置角色：`saint`
- 随之挂载的行为：`ascend`

无可调参数。

### 爆破 `pyro`

空中爆跳（手动控制可招架）；每跳燃料 +1、随时间回落，过热眩晕、满了自爆；水下憋气降到 drown_burst_air 即溺爆。AI 只在燃料 ≤ heat_cap 时爆跳，永不自爆。

- 内置角色：`artificer`
- 随之挂载的行为：`pyro_romp`、`pyro_maul`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `heat_cap` | 5 | 0 ~ 9 | AI 自主爆跳的燃料上限，默认为过热警告线，不会眩晕或自爆 |
| `drown_burst_air` | 0.65 | 0 ~ 0.95 | 水下憋气剩余降到此值即溺爆（也是气量条的死亡下界） |

### 高后空翻 `acrobat`

规划器可用加强后空翻够取高处目标；行为后空翻上横杆 / 后空翻劫持光标随之挂载。

- 内置角色：`rivulet`
- 随之挂载的行为：`riv_flip`、`riv_snatch`

无可调参数。

### 水生 `aquatic`

水生体质（潜泳冲刺 / 低水阻 / 浮泳拖臀）。耗气倍率另见数值 lungs_fac。

- 内置角色：`rivulet`

无可调参数。

### 重压 `heavy`

气喘到 exhaust_enter 累倒，降到 exhaust_exit 缓过来；累倒时跑、爬变慢，喘气闭眼，滑铲变弱、翻滚恢复普通限制、扔东西无力。没累倒时翻滚不自然停。从高处落下震动窗口；砸、滚、滑撞到别的猫会让它晕（不算到人头上：不扣好感、醒来不生气），撞到蝙蝠会砸死。扔矛一下就气喘到顶：没累倒时矛伤害极高、身体顺势冲出（手操时在地上翻滚、空中空翻），累倒时扔出的矛几乎没伤害。滑铲速度、跳跃耗气、摔晕阈值等另见数值。

- 内置角色：`gourmand`
- 随之挂载的行为：`catch_breath`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `exhaust_enter` | 0.95 | 0 ~ 1 | 气喘达到此值累倒 |
| `exhaust_exit` | 0.4 | 0 ~ 1 | 累倒后气喘降到此值以下缓过来 |
| `land_shake` | 1 | 0 ~ 5 | 落地震动倍率，0=不震 |
| `land_shake_speed` | 8 | 0 ~ 60 | 落地速度达到此值才震 |
| `slam` | true |  | 砸、滚、滑撞到别的猫时让它晕 |

### 骨针 `needle`

不能用嘴吃东西。站着不动、有空手时从尾巴上拔骨针。连着身体扔出的骨针扎中或穿过活物给 1/4 格食物；落地、扎住或被别人拿走就断开，变成普通的矛。

- 去掉标签：`mouth`
- 内置角色：`spearmaster`

无可调参数。

## 行为

### 取果 `fetch`

饿了去拿能吃的东西（果子、黏菌、蝙蝠、蛋虫蛋）。真饿了拿到就吃；只是有点饿时可能先揣着到处走，过一阵或真饿了再吃。手里留着一个就不再去拿。游泳和失重时游 / 飘过去抓住就地吃。会啃肉的猫（猎手、工匠、大胃王）也啃蛋虫尸体：拿起来伏下身子啃，啃完扔开。

- 需要身体标签：`mouth`
- 用到的物品：`edible`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `carry_chance` | 0.5 | 0 ~ 1 | 有点饿时拿到先揣着、过会儿再吃的概率 |

### 生气扔石头 `anger`

被砸晕或惹急后生气：捡起能扔的东西瞄准光标扔，消气前一直盯着。好感很低时偏向拿矛；骨针猫地上没武器时从尾巴拔骨针。

- 需要身体标签：无（所有猫）
- 用到的物品：`throwable`

无可调参数。

### 上横杆 `poles`

吊上横杆、翻上来站好（舌头猫甩舌头、溪流后空翻抓杆都走这里），站稳后交给爬架行为。

- 需要身体标签：无（所有猫）
- 用到的物品：`climbable`

无可调参数。

### 发呆 `idle`

默认状态：站着发呆、东张西望、踱步、对视；无重力时漂浮。闲待一阵后按需求和性格随机挑下一件事。

- 需要身体标签：无（所有猫）

无可调参数。

### 取暖 `warmth`

冷了去暖源旁边取暖：冷度越高越想去，和别的事按比例挑；冷到阈值就强制去。

- 需要身体标签：无（所有猫）
- 用到的物品：`warm`

无可调参数。

### 休息 `rest`

累了歇一会，体力告急强制趴下。困了睡：食物够就冬眠（扣食物、回满体力），不够就打个盹；困到撑不住就地睡。

- 需要身体标签：无（所有猫）

无可调参数。

### 游泳 `swim`

落水后的游泳状态：漂游、潜泳取食、在水面休息。喜不喜欢水看性格 swim_zeal。

- 需要身体标签：无（所有猫）

无可调参数。

### 让路 `makeway`

别的猫要从这里过时让开：地上趴下让它跨过去，横杆上换到杆的另一面，竖杆上顺着挪开；停在别的猫身上又不走时自己跳下来。自己走到一半路断了就放下这件事。

- 需要身体标签：无（所有猫）

无可调参数。

### 找横杆 `seek_hpole`

场上有横杆时，想玩就用舌头钩上去（高杆先爬墙再钩），之后横杆玩耍。

- 需要身体标签：`tongue`
- 心情名（toy_pref 键）：`hpole`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.72 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.3 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.0035 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.0006 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `energy_fac_fresh` | 1.3 | 0 ~ 10 | 体力满时的权重系数 |
| `energy_fac_tired` | 0.1 | 0 ~ 10 | 体力空时的权重系数 |

### 爬墙 / 天花板玩耍 `wall_climb`

走到墙脚用舌头爬上天花板吊着晃，玩腻了松手落下。

- 需要身体标签：`tongue`
- 心情名（toy_pref 键）：`ceiling_play`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.75 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.1 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.0018 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.00038 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `energy_fac_fresh` | 1.3 | 0 ~ 10 | 体力满时的权重系数 |
| `energy_fac_tired` | 0.15 | 0 ~ 10 | 体力空时的权重系数 |

### 舔光标 `cursor_lick`

光标停在屏幕中下部、离猫够近够久：伸舌去舔（好感越高等得越短），舔到加好感。

- 需要身体标签：`tongue`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `dwell_ticks` | 200 | 1 ~ 4000 | 光标驻留基准 tick（好感 -1 时 ×1.5，+1 时 ×0.5） |
| `gate_frac` | 0.333333 | 0 ~ 1 | 光标与猫水平距离 < 屏宽 × 此值才会舔 |
| `relick_cooldown` | 60 | 0 ~ 100000 | 舔完后的冷却 tick |
| `temper_gain` | 0.1 | -1 ~ 1 | 成功舔到一次的好感变化 |

### 超度 `ascend`

业力满且好感 ≤ temper_gate 时：杀死弹窗出现、被拎住 grab_ticks、被砸晕醒来，都会超度（比躲杀优先）。

- 需要身体标签：`ascension`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `temper_gate` | -0.2 | -1 ~ 1 | 好感 ≤ 此值（且业力满）才会超度 |
| `grab_ticks` | 200 | 1 ~ 100000 | 被光标拎住这么久（tick）且满足条件 → 超度 |

### 舌头躲杀 `dodge_kill`

杀死弹窗出现时用舌头点「取消」（够不到就先爬墙）；游泳中不躲。被这样取消会扣好感。

- 需要身体标签：`tongue`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `cancel_temper` | -0.2 | -1 ~ 1 | 自己用舌头取消杀死弹窗时的好感变化 |

### 后空翻上横杆 `riv_flip`

无聊时找一根够得着的横杆，走到杆下后空翻上去，抓住就转横杆玩耍，抓不上落地收工。

- 需要身体标签：`acrobat`
- 心情名（toy_pref 键）：`riv_flip`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.72 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.3 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.004 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.00055 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |

### 后空翻劫持光标 `riv_snatch`

光标停在离地不高处够久：跑位、后空翻掠过时叼走光标，落地后贴身带着它走一会再放开。

- 需要身体标签：`acrobat`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `dwell_ticks` | 200 | 1 ~ 4000 | 光标在高度带内停留多少 tick 才触发 |
| `carry_min` | 200 | 1 ~ 4000 | 叼住后最短带多久（tick） |
| `carry_max` | 400 | 1 ~ 4000 | 叼住后最长带多久（tick） |
| `cooldown` | 1200 | 0 ~ 100000 | 成功劫持后的冷却（tick） |
| `cooldown_abort` | 300 | 0 ~ 100000 | 放弃 / 扑空后的冷却（tick） |

### 爆跳撒欢 `pyro_romp`

无聊时找块空地连续爆跳几下；燃料不够一整轮就不玩。

### 爆跳扑咬 `pyro_maul`

好感低时，光标从身边经过后移远：概率爆跳扑上去叼住；光标贴身停留：走过去叼住。叼住啃几口后松开。

- 需要身体标签：`pyro`

| 参数 | 默认 | 范围 | 说明 |

| `near_ticks` | 120 | 1 ~ 4000 | 光标贴身停留多少 tick 后走过去叼 |
| `cooldown` | 1200 | 0 ~ 100000 | 扑咬后冷却 tick（两种模式共用） |

### 留个果子 `forage`

吃饱时附近还有能吃的，会顺手捡一个带着去睡，最多一个；醒来饿了先吃它。

### 累倒喘气 `catch_breath`

累倒后停在原地喘气，缓过来再做别的。

- 需要身体标签：`heavy`

无可调参数。

### 失重吐舌 `zerog_lick`

失重漂着（闲逛或追食物）时，偶尔朝要去的地方吐舌，粘住墙就借力。

- 需要身体标签：`tongue`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `prob` | 0.02 | 0 ~ 1 | 每 tick 吐舌的概率 |
| `min_dist` | 60 | 0 ~ 1000 | 离目标这么远才吐 |

### 打猎 `hunt`

饿了又没现成吃的时拿武器打活物，最多扔三次：飞着的蝙蝠用石头或矛，蛋虫只用矛（石头只能砸晕）；骨针猫只用自己拔的骨针。蛋虫看见武器飞来会跳开，所以先冲上去逼它跳，等它落地还跳不动时再扔。投掷技能为 0 的猫（僧侣、圣徒）不打猎。

- 需要身体标签：无（所有猫）
- 用到的物品：`edible`

无可调参数。

### 爬架 `perch`

闲下来时去杆上随机一处待一阵，待够了换个地方或下来；合群的猫爱往别的猫旁边凑。

- 需要身体标签：无（所有猫）
- 用到的物品：`climbable`

无可调参数。

### 躲雨 `rain`

大雨时露天的猫会被推动、砸晕，被光标拎着和定身时不受影响；雨将变大时走到最近的窗口下躲雨。

- 需要身体标签：无（所有猫）

无可调参数。

### 定身 `hold`

用户让它定身时停在原地保持姿势，只留看向、眨眼、呼吸和尾巴；需求和寒冷不变。被晕、被拖、游泳之后在落点接着定身。

- 需要身体标签：无（所有猫）

无可调参数。

### 挨着睡 `huddle`

要歇一会、要睡、懒着趴下时，附近有想亲近、也不嫌弃自己的猫（看亲和和关系）正在地上趴着，就先走到它身边背靠背趴下。挨着趴的猫关系涨得快，暴风雪里变冷得慢。

- 需要身体标签：无（所有猫）

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `min_pull` | 0.4 | -1 ~ 1 | 想靠近对方至少这么多才去挨着（亲和与关系换算，见 social.pull） |
| `min_accept` | 0 | -1 ~ 1 | 对方想靠近我至少这么多才肯让我挨着 |
| `reach` | 700 | 0 ~ 5000 | 只找这么远以内的 |

### 分享 `share`

自己吃够了（够冬眠）、手里留着吃的，附近有想亲近的猫（看亲和和关系）饿着、也能吃这个，就拿过去放在它身边，留给它一阵子。两只猫关系变好。

- 需要身体标签：`mouth`
- 用到的物品：`edible`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `min_pull` | 0.4 | -1 ~ 1 | 想靠近对方至少这么多才分享（亲和与关系换算，见 social.pull） |
| `chance` | 0.3 | 0 ~ 1 | 每次检查到能分享时真去分享的概率 |
| `reach` | 700 | 0 ~ 5000 | 只找这么远以内的 |
| `cooldown` | 1200 | 0 ~ 100000 | 分享过一次后多久再考虑 |

### 玩珍珠 `pearl_play`

闲着时去拿一颗落在地上的珍珠，拿着走走看看，最后放下或随手抛开；去吃东西、拿武器要腾手时会先放下它。

- 需要身体标签：无（所有猫）
- 用到的物品：`toy`
- 心情名（toy_pref 键）：`pearl_play`

| 参数 | 默认 | 范围 | 说明 |
|---|---|---|---|
| `mood_base` | 1 | 0 ~ 10 | 心情基础权重（再乘性格权重 Traits.mood_weight） |
| `mood_start` | 0.6 | 0 ~ 1 | 新鲜度回升过此值才会被选中 |
| `mood_quit` | 0.3 | 0 ~ 1 | 持续型心情：新鲜度降到此值就收工 |
| `mood_init` | 0.9 | 0 ~ 1 | 出生时的新鲜度 |
| `mood_decay` | 0.003 | 0 ~ 1 | 做这件事时每 tick 新鲜度下降量 |
| `mood_recover` | 0.0005 | 0 ~ 1 | 不做时每 tick 新鲜度回升量 |
| `hold_min` | 150 | 30 ~ 2000 | 拿着晃的最短帧数 |
| `hold_max` | 420 | 30 ~ 2000 | 拿着晃的最长帧数 |
| `stroll_prob` | 0.012 | 0 ~ 1 | 拿着时每 tick 想走几步的概率 |
| `toss_prob` | 0.5 | 0 ~ 1 | 玩够了随手抛开（而不是放下）的概率 |
| `toss_speed` | 7 | 1 ~ 30 | 抛出的初速（逻辑 px/tick） |
